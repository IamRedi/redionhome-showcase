# Media provenance

Application screenshots are captured from the actual loopback showcase with
public CC0 panoramas and virtual devices. No household photo, original database
or real provider connection is used. Videos are silent, captioned montages of
these screenshots, not continuous interaction recordings or live AI demos.

Poly Haven license and both asset pages were checked on 27 October 2026:
https://polyhaven.com/license
https://polyhaven.com/a/artist_workshop
https://polyhaven.com/a/brown_photostudio_02

File checksums, dimensions, source identity and review state are in
`docs/assets/media-manifest.json`. The owner reviewed the preview and explicitly
approved these exact assets for publication in this showcase on 27 October 2026.
Approval applies to this GitHub repository; other publication targets require
their own editorial decision.
