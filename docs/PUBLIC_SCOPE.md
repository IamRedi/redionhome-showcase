# Evaluation scope

Included: the F3 source foundation, local CC0 demonstration, actual visual
editor, stable objects and revisions, separate showroom profiles, role guards,
permission-scoped virtual actions, saved ambients, audit UI, deterministic
assistant responses and automated regressions.

Excluded: the owner's home photographs, real database, product connections,
private network URLs, provider credentials, installed releases, backups and
original Git history. This repository is not connected to the original updater.

Live AI and speech recognition are disabled. The current UI is Albanian;
English/German documentation and video captions do not imply full product
localization. Browser mobile emulation does not prove physical phone or device
acceptance. Complete F3 hardware control and later product phases are not
claimed. See EVIDENCE.md for exact tests and remaining limitations.
