# Demonstration media only

These are two independent places, **not the owner's home**. Portal connections and object/device positions are illustrative, not surveyed geometry. This demonstration set contains no private media. Separately provided panoramas are stored only in the private installation and are not part of this set.

- `studio.jpg`: [Artist Workshop](https://polyhaven.com/a/artist_workshop), Oliksiy Yakovlyev, CC0.
- `lounge.jpg`: [Brown Photostudio 02](https://polyhaven.com/a/brown_photostudio_02), Sergej Majboroda, CC0.
- [Poly Haven license](https://polyhaven.com/license).

Run `npm run demo:fetch`. Originals are downloaded to this ignored folder and checked against pinned SHA-256 values before use. Startup copies them unchanged into private installation storage, records SHA256, and creates 1024px previews and 2048/4096px tiled derivatives. Never place private images under `public/`, `dist/`, or Git.
