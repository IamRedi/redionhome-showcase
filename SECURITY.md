# Security and privacy

Use `npm run demo`, which creates a dedicated synthetic workspace and an
allowlisted child environment. Provider credentials, personal HOME, Tailscale
origins and existing data paths are not inherited. The process-level guard
blocks external fetch, DNS names and TCP connections. Provider setup writes are
denied in showcase mode. AI replies are deterministic scripts, not model calls.

The demonstration login is a public fixture password. Keep the service on
loopback; do not expose this evaluation instance or add personal media. The
original private home, its data, credentials and device commands are outside
this repository and are never needed to run the showcase.

The application retains its real owner/viewer/visitor authorization and its
separate approved-showroom contract. Tests exercise these boundaries but are
not a security certification. Review every panorama's pixels before publishing
a real tour: hiding a hotspot does not hide something visible in a photograph.

Report concerns privately via the author's GitHub profile. Never post access
tokens, household images or private network details in issues.
